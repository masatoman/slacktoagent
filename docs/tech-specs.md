   - Express.js
   - Winston（ロギング）

2. 外部連携

   - 認証: APIキー

2. 内部API

   - 設定管理API
   - ログ管理API

## API ドキュメント
### Swagger UI
- アクセスURL: `http://localhost:3456/api-docs`
- 提供機能:
  - APIエンドポイントの一覧表示と詳細説明
  - リクエストパラメータの入力フォーム

  - APIキー認証のテスト

### 認証
- APIキー認証
  - ヘッダー名: `X-API-Key`
  - 開発用APIキー: `test_api_key`
  - 管理者用APIキー: `test_admin_api_key`

### 利用可能なエンドポイント
1. ヘルスチェック
   - エンドポイント: `/health`
   - メソッド: GET
   - 認証: 不要

2. 認証

   - ログアウト: `/auth/logout` (POST)

3. エージェント実行
   - エンドポイント: `/execute`
   - メソッド: POST
   - 認証: 必要（APIキー）

4. 管理者機能
   - サーバーステータス: `/admin/status`
   - メソッド: GET
   - 認証: 必要（管理者APIキー）

## 設定管理のルール

### 環境変数と設定ファイルの取り扱い

1. **設定変更の基本原則**
   - 既存の設定値を必ず確認してから変更を行う
   - 変更が必要な値のみを更新し、他の値は保持する
   - 特にURLやAPIキーなどの重要な設定は慎重に扱う

2. **設定変更のプロセス**
   ```
   1. 変更前：既存の設定をバックアップまたは記録
   2. 確認：変更が必要な項目を特定
   3. 変更：必要な項目のみを更新
   4. 検証：変更後の設定値を確認
   5. テスト：変更による影響をテスト
   ```

3. **重要な設定項目**
   - APIキー（API_KEY, ADMIN_API_KEY）
   - Webhook URL（SLACK_WEBHOOK_URL）
   - 環境固有の設定（PORT, NODE_ENV）
   - 接続情報（REDIS_URL, ALLOWED_ORIGINS）

4. **設定変更の記録**
   - 変更内容をコミットメッセージに明記
   - 重要な変更は技術文書に記録
   - 変更理由と影響範囲を文書化

## ポート設定
- デフォルトポート: 3456
- 環境変数 `PORT` で設定可能
- 設定箇所:
  - `.env`
  - `docker-compose.yml`
  - `src/config/server.js`

### 重要な注意点
- ポート設定を変更する場合は、以下の3つのファイルで一貫性を保つ必要があります：
  1. `.env` の `PORT` 変数
  2. `docker-compose.yml` の ports マッピングと environment の PORT
  3. `src/config/server.js` の `SERVER_CONFIG.port`
- `src/index.js` ではポート設定を行わず、`server.js` の設定を使用します
